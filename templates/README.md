# Research templates

These are empty schemas for later work. They do not indicate that any artifact has been collected or test executed.

| Template | Use |
| --- | --- |
| [observation.md](observation.md) | Source statement, measured observation, inference, or hypothesis |
| [finding.md](finding.md) | A candidate finding; keep unverified until criteria are met |
| [lab-session.md](lab-session.md) | Later session scope, state, commands, and outcomes |
| [artifact-manifest.csv](artifact-manifest.csv) | Provenance and identity for each original/derived artifact |
| [device-inventory.csv](device-inventory.csv) | Sanitized hardware/device identifiers and revisions |
| [endpoint-inventory.csv](endpoint-inventory.csv) | Candidate/observed operations and evidence status |

Copy templates when needed. Keep raw evidence in the protected evidence store described in [the evidence method](../docs/07-evidence-method.md). Publish only sanitized copies of completed records.
